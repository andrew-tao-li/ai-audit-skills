🛡 护栏一张图必须连"不能做什么"一起说清

🚧 边界：它不做什么

  • 不判断业务实质——费用是否真实发生，它不知道
  • 不做舞弊 / 拒付认定——异常只是"要看的线索"
  • 不验发票真伪（需外部数据）· 不连银行流水
  • 制度阈值只能来自你给的制度，不替你假设
  • 不写业务系统、不改原始资料

⚠️ 风险：用之前要知道

  • 异常 ≠ 舞弊；未发现问题 ≠ 没有问题
  • 会有漏报和误报——它只做优先级排序
  • 先在合成样例上验证，再上真实数据
  • 输出目录可能含敏感信息，按保密要求存放
  • 最终定性必须由有资质的人做

🔒 安全与隐私

  • 全程离线：不联网、不上传、无外部服务
  • 不内置任何密钥，不调任何大模型 API
  • 只读输入，输出只写到新目录
  • 不静默丢弃：排除/压制的内容都单独留痕
  • 事实 / 推断 / 假设 / 判断分开；可复现（哈希）
