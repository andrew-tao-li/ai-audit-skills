# SkillHub 与 WorkBuddy：关系、指标口径、搜索实测

> 2026-10-27 实测记录。起因：用户在 WorkBuddy 里装了很多次，日报却一直显示「安装 0」。

## 一、两个产品是什么

| 产品 | 定位 | 来源 |
|---|---|---|
| **SkillHub**（skillhub.cn / skillhub.tencent.com） | 腾讯云 Lighthouse 团队做的 **AI Skills 社区**，是 OpenClaw 官方生态 ClawHub 的**本土化镜像**；技能从这里上架、审核、分发 | 腾讯云开发者社区《腾讯上线 SkillHub》 |
| **WorkBuddy**（workbuddy.cn） | 腾讯的**个人 AI 助手**（CodeBuddy 架构），自带技能市场，卡片标注「使用量 / 安装量」 | WorkBuddy 官方文档《技能市场》 |

**数据流向**（推断 + 实测一致）：

```
我们 publish → SkillHub 平台（审核、存储、统计）
                   ↓  WorkBuddy 技能市场里「SkillHub」分区直接取平台数据
              WorkBuddy 客户端（用户点 + 安装 → 落到本地技能目录）
                   ↑
      我们只读 /api/skills 拉统计（evolution/skillhub_stats.py）
```

也就是说：**我们上架的是 SkillHub，WorkBuddy 是它的前端之一**（另一个是 Marvis 等）。WorkBuddy 里安装 = 从 SkillHub 取包，计数回到 SkillHub。

## 二、「安装 0」是怎么回事（已确认为平台字段问题）

`GET https://api.skillhub.cn/api/skills?keyword=<slug>` 返回的字段里：

```
installs: 0          ← 恒为 0，平台未填充
downloads: 317       ← 真实增长（286 → 317）
stars: 1
score: 100000
claim_state: unclaimed
verified: false
```

- 用户在 WorkBuddy 里**确实安装过多次**，`installs` 仍是 `0`；
- 同期 `downloads` 从 286 涨到 317（+31）。
- 结论：**安装动作被计入 `downloads`，`installs` 平台没有填充**。此前日报只印 `installs`，
  于是每天看起来都是"0 安装"——是**我们的呈现方式误导**，不是没人装。

**已修**：`evolution/skillhub_stats.py` 在 `installs == 0` 时不再展示该字段；为 0 的字段只在有值时出现
（将来平台填了会自动显示）。

## 三、搜索实测（2026-10-27，直连平台 API）

同样的 `keyword` 参数，就是市场搜索用的口径。样本见下：

| 关键词 | 命中总数 | 我们的名次 | 前 3 名（与关键词的关系） |
|---|---|---|---|
| `费用报销审计` | 52 | **第 11 位**（第 2 页第 1 条） | 电商设计大师(9594 下载)、韶关学院—校知星球Skill(514)、跨境出海AI助手(395) |
| `报销审计` | 194 | 第 33 位 | 会议纪要(171737)、合同台账统计(224)、电商设计大师(9594) |
| `费用审计` | 811 | 前 60 未见 | 审计追踪(2173)、会计审计(3735)、七猫小说写作助手(37709) |
| `报销` | 2478 | 前 60 未见 | 中医药行业日报(674)、招投标行业情报分析(68320)、公文写作(42530) |

**结论**：

1. 平台搜索**不是**按文本相关性排的——精确输入 6 个字，前 10 名与关键词毫无关系；
2. 排在前面的普遍是**下载量高**的技能（数千到十几万），我们 317 属低位；
3. 我们的 `displayName` 就是 `费用报销审计`（整词一致），仍只到第 11 位 → **文本已经最大化，排序由热度主导**；
4. 因此：**靠改文案把排名顶到第一，不现实**；能动的杠杆只剩下载/收藏/评论/认证。

## 四、还能做什么（按性价比）

| 杠杆 | 现状 | 说明 |
|---|---|---|
| 下载量 | 317 | 唯一真正影响排序的信号；靠真实推广与内容 |
| 收藏 / 评论 | 1 / 0 | 平台卡片可见，影响转化，也影响权重 |
| 认领 / 认证 | `claim_state=unclaimed`、`verified=false` | 平台有「企业认证蓝V」；个人可申请 → 可能带来权重与信任 |
| 上架文案 | 已优化（0.2.47） | 标签含「费用报销审计」整词、简介首句即整词 |

## 五、给日报的固定口径

以后再看 SkillHub 数据，只用两行：

- **下载**＝真实使用量（含安装）；
- **收藏 / 评论**＝真实反馈。

**不再引用「安装」**，除非该字段开始有值。
