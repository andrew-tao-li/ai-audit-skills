# 给真实审计师的 30 分钟试用指南

> 你是审计行业的从业者。我们想请你花 30 分钟，试用一下我们的审计 Skill 工具。
>
> 你不需要懂代码。我们给你一份"最小需求清单"——告诉我们这 5 项内容即可。

---

## 你需要做的（总共 30 分钟）

### Step 1: 装上 skill（5 分钟）

#### 选项 A：用有道龙虾 / WorkBuddy（5 分钟）

1. 装桌面应用（如果你没装）
   - 有道龙虾：https://lobsterai.com
   - WorkBuddy：腾讯应用商店搜"WorkBuddy"
2. 进入"技能"或"Skill"管理界面
3. 选"上传 .zip"或"添加 Skill"
4. 从以下任一下载 zip：
   - https://github.com/andrew-tao-li/ai-audit-skills/releases/latest
5. 上传 3 个 zip（每个对应一个 Skill）
6. 完成

#### 选项 B：用 OpenCode 桌面应用（5 分钟）

1. 装 OpenCode（如果没装）
2. 设置 → 技能 → 添加技能
3. 选"从文件夹"
4. clone https://github.com/andrew-tao-li/ai-audit-skills 后选 `skills-v2/<skill-name>/`

---

### Step 2: 用合成样例跑一次（5 分钟）

装好后，对桌面应用说：

> "请用 expense-audit skill 跑一下它包内的 examples/input 样例。"

桌面应用应该自动跑通、生成 finding 和报告。

如果跑成功 → 工具装好了。
如果报错 → 把错误截图发给我们（这是反馈）。

---

### Step 3: 用你公司**脱敏后**的真实数据试一次（15 分钟）

请**任选一种** skill（建议从 expense-audit 开始，因为它最简单）。

**重要**：所有数据必须**脱敏**（公司名→A 公司、人名→员工甲、银行号→1234 5678 9012 3456）。

#### 准备什么？

- **1 份 CSV 文件**（推荐 50-200 行数据）
- 文件字段示例（expense-audit）：
  ```
  报销单号,工号,部门,费用类型,发生日期,金额,币种,商户,发票号,审批人,事由
  EXP-001,E001,销售,差旅,2026-09-01,800,CNY,酒店A,INV-001,A100,客户拜访
  EXP-002,E002,采购,办公,2026-09-02,300,CNY,文具店,OFF-001,A200,办公用品
  ...
  ```
- **如果** 你只想描述场景不给数据：直接用文字描述场景也可以，AI 工具会跑合成数据测

#### 你最想看哪类场景？

告诉我你**最关心**的几类问题（多选即可）：

- [ ] 员工报销有没有违规（重复发票、自审自批、超标）
- [ ] 采购流程有没有舞弊（马甲供应商、围标、拆单）
- [ ] 内部调查证据链（保管链、时间线、关系图）
- [ ] 中国民营制造业特有舞弊（高发场景）
- [ ] 其他（请描述）：_______________

## 真实审计师的最小需求清单

**如果你只给我们 3 件事**（最低限度）：

1. **你公司的审计场景描述**（1 段话）
   - 例："我们是民营制造业，年营收 5 亿，200 人，常发生销售员虚开发票、仓储虚报物料"
2. **你跑出来的 finding 类型**（哪些有用哪些没用）
3. **1-2 个真实脱敏案例**（1 个 expense 或 procurement 数据 CSV 即可）

这 3 件事能帮我们：
- 知道我们做的方向对不对
- 知道哪些 finding 类型要加 / 要减
- 知道真实数据的特征，下次 LLM 自主出题可以更贴近

## 你的反馈会怎么用？

我们**不会**自动改 skill。所有反馈必须经过人工 review（审计工具的特殊性）。

**反馈处理流程**：
```
1. 收集反馈 (GitHub Issue / 邮件 / 微信)
2. 每月 1 次人工 review（开发者看）
3. 决定哪些进 v0.3 路线图
4. 每月给所有贡献者发"本月进展"邮件
```

**承诺**：
- 你的真实数据**只用于测试**，**不会**进 commit
- 你的反馈**会**影响我们的优先级排序
- 你的名字（如果愿意）会出现在"致谢"里

## FAQ

**Q：我不懂代码，能试用吗？**
A：能。装 skill 时用桌面应用，传数据用对话，工具自动跑。

**Q：传真实数据安全吗？**
A：脚本本身**完全离线**。但**你使用的桌面应用可能上传数据**到云端 LLM——所以请**先脱敏**再用。

**Q：跑出来不准怎么办？**
A：这就是我们想要的反馈。"不准"和"为什么不准"才是最有价值的信息。

**Q：必须装吗？**
A：不。我们欢迎纯文字反馈。比如："我觉得销售费用这块应该能识别跨月重复报销"。
