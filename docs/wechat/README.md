# 公众号卡片（手机适配版 · 8 张）

**用途**：公众号正文以图为主、按顺序发这 8 张。**不要**改图内文案时手改 PNG——改生成器再重跑。

## 手机适配的三条硬规则（为什么是 750 宽、为什么字这么大）

1. **公众号图片按文章宽度显示（约 375px）**。
   设计稿宽 **1080** → 压到 375 = **2.9 倍缩小**：14px 正文在手机上只剩 **5px**（看不清）。
   → 所以画布用 **750**（正好是 375 的 2 倍），**正文 ≥32px**（750→375 是 2 倍，32→16px ✅）。
2. **一张只讲一件事、高度 1~1.5 屏**，让人"一直往下划"，而不是被一张长图劝退。
3. **繁复细节要砍**：43 条规则**不逐条列**，每个域只留 **2~3 条代表**（完整清单留给 `docs/expense-audit-topology.md`）。

## 重新生成

```bash
python3 scripts/build-wechat-cards.py     # 读该脚本里的文案 → 出 HTML + PNG 到 docs/wechat/
```
（依赖本机 Chrome 无头截图；改文案改脚本顶部的卡片内容即可。）

## 尺寸
- 设计宽 750px，**2 倍导出** → PNG 实际 **1500px 宽**（Retina 清晰）。
- 高度按内容自适应（2000 ~ 3430px），单张 0.5 ~ 1.2 MB。
