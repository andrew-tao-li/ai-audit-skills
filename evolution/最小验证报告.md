## 四、重要的架构发现

### ⚠️ 关键限制：launchd 不能调用 OpenCode

```
$ which opencode
opencode not found
$ file /Applications/OpenCode.app/Contents/MacOS/OpenCode
Mach-O 64-bit executable arm64  # GUI 应用，不是 CLI
```

**OpenCode 是 Electron GUI 应用**，launchd 后台运行没有 Aqua session，**无法调用 MiniMax 模型**。

### 调整后的循环架构

```
┌──────────────────────────────────────┐
│  launchd 后台（无 LLM）               │
│  - 每天 9:00 自动跑 ./evolve.sh      │
│  - 跑测试 + 评分 + 更新 state.json  │
│  - 发现失败 → 写入 open_failures     │
└──────────────────────────────────────┘
                  ↓
        发现 open_failures > 0
                  ↓
┌──────────────────────────────────────┐
│  用户启动 OpenCode session            │
│  - 用户输入 "继续"                    │
│  - AI 读 state.json + open_failures │
│  - AI 分析根因 + 提议修复           │
│  - 用户审批 → 修改代码              │
└──────────────────────────────────────┘
                  ↓
         重新跑 ./evolve.sh 验证
                  ↓
            分数提升？
                  ↓
            进入下一轮迭代
```

**关键**：launchd 跑**机械部分**（测试+评分+状态），OpenCode 跑**智能部分**（分析+修复）。两者通过 `evolution/state.json` 桥接。

## 五、用户实际操作流（最小验证版）

```
第一次启动 OpenCode 后：
1. 说："帮我跑一下 ./evolve.sh 看看 baseline"
2. AI 跑测试，看到 F1=93%，说"有 11 个失败需要分析"
3. 说："分析 complex_01_full_audit 的 split-expense 误报"
4. AI 读代码 + fixture，提议修复
5. 你审批
6. 再跑测试，看分数变化

如果想自动化：
1. 安装 launchd：./evolution/install_launchd.sh install
2. 每天 9:00 自动跑测试，state.json 自动更新
3. 你偶尔打开 OpenCode 看 state.json，说"继续"即可
```

## 六、下周方向（Layer 1：进入自演化循环）

### 优先级 1：修复暴露的 11 个问题

按重要性排序：
1. **#9 price-outlier 漏报（马甲供应商互相掩护）**——这是真实业务最危险场景
2. **#11 process-receipt-before-approval 漏报**——changelog 与实现不符，必须修
3. **#4 near-duplicate 漏报**——复合场景下未触发，需调查原因
4. 其他误报问题——调整阈值或加排除规则

### 优先级 2：扩展测试集

- 加 5-10 个复合场景（更接近真实业务的复杂度）
- 加"边界条件"测试（如金额刚好在阈值上、日期刚好在范围边缘）
- 加"季节性"测试（季末突击报销等）

### 优先级 3：进入改进代理（Layer 2）

- 写 `improvement_agent.py`：自动分析失败案例 + 提议修复
- 写 `A/B 测试` 框架：每个改进必须保证 F1 不退步
- 加"业务合理性自检"：每个新规则必须通过 AI self-critique

## 八、诚实承认的不足

1. **fixture 设计仍偏简单**：复合场景只有 5 个，远不够覆盖真实业务
2. **没有真实业务数据**：所有 fixture 都是合成，真实场景会有更多边缘情况
3. **没有业务合理性检查**：AI 提议的修复可能"代码正确但业务无意义"
4. **没有自动改进**：必须人工读 state.json + 触发 AI 分析
5. **跨平台兼容性**：未在 Windows/Linux 上测试
