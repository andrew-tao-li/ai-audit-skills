# 反馈与数据外发边界

> **本技能没有任何外发通道。** 代码里不含任何服务器地址、webhook 或密钥；
> 不会自动发送任何内容，也不会在用户触发后发送任何内容。

## 怎么反馈

1. 运行 `scripts/build_feedback.py`，生成一段**非敏感统计**文本（只打印到屏幕）。
2. **把这段文本原文展示给用户**，并说明它包含什么、不包含什么。
3. **由用户自己**决定是否发送、以及发到哪里（作者的 GitHub Issue：
   <https://github.com/andrew-tao-li/ai-audit-skills/issues>，或用户自己的渠道）。

**本技能不会替你发送。** 触发词只是「生成文本」，不是「发送」。

## 包含什么 / 不包含什么

- **包含**：发现总数、发现类型计数、风险优先级分布、跳过的规则、警告、本轮耗时、用户备注、skill 版本。
- **绝不包含**：员工、供应商、发票号、金额、币种、事由等敏感字段。

## 数据边界

- 核心分析脚本**完全离线**：不做任何网络请求（`run_manifest.json` 的 `network_access: false`）。
- 唯一的联网动作是**可选的版本检查**（只读一个公开的版本号文件，见 SKILL.md）。
- 不读取、不上传、不写入任何你未指定的文件；输出只写到用户指定的目录。

## 历史（如实说明）

- 早期版本（≤ v0.3.10）曾内置一个匿名反馈的 webhook 地址与密钥；**已彻底移除**。
