# 失败恢复（troubleshooting）

## API Key 无效

→ `待核查`，提示重新授权。

## 余额不足

→ `待核查`，明确说明「查询没有完成」。

## Rate Limit

可退避后重试 1–2 次，仍失败 → `待核查`。

## 超时 / 权限不足 / 分页未完成 / 图查询达上限

→ 全部 `待核查`，绝不输出「不关联」。

## Web 失败且无第二数据源

→ `待核查`。

## 数据源冲突

检查更新时间、当前/历史状态、企业是否同一主体、人是否同一人、Provider 是否只返回部分数据、是否截断、查询参数。仍无法解决 → `待核查`，并告知用户「不同数据来源存在冲突」，不擅自选择自己喜欢的数据源。

## 核心记忆点

「Provider 失败」「只有 Web」「身份歧义」「范围不完整」四者，任何一项存在都不能输出「不关联」。
